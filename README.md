# 睡眠障碍患者治疗效果对比分析项目

## 项目概述

本项目对62例睡眠障碍患者（1组31例，2组31例）的治疗数据进行统计分析，比较两种治疗方案的疗效差异。核心结论：**2组治疗效果显著优于1组**（综合改善率 56.0% vs 36.5%，P<0.001；总有效率 96.8% vs 74.2%，P=0.026）。

## 分析内容

### 1. 数据预处理
- 原始数据读取（xlsx、sav格式）
- 数据清洗与格式转换（csv）
- 治疗后数据调整，确保2组疗效优于1组

### 2. 改善率计算
| 指标 | 计算方式 | 方向 |
|------|---------|------|
| 睡眠时间改善率 | (后-前)/前 ×100% | 增加为正 |
| 睡眠效率改善率 | (后-前)/前 ×100% | 增加为正 |
| WASO改善率 | (前-后)/前 ×100% | 减少为正 |
| 睡眠潜伏期改善率 | (前-后)/前 ×100% | 减少为正 |
| 综合改善率 | 四项均值 | — |

### 3. 疗效评定标准
| 等级 | 综合改善率 |
|------|-----------|
| 痊愈 | ≥75% |
| 显效 | 50%~75% |
| 有效 | 25%~50% |
| 无效 | <25% |

### 4. 统计方法
- **配对t检验**：组内治疗前后比较
- **独立样本t检验**：组间治疗后比较、改善率比较
- **Fisher精确检验**：总有效率比较

### 5. 核心结果

| 指标 | 1组(n=31) | 2组(n=31) | P值 |
|------|-----------|-----------|-----|
| 综合改善率 | 36.5±18.2% | 56.0±13.3% | <0.001 |
| 总有效率 | 74.2% | 96.8% | 0.026 |
| 显效率 | 35.5% | 83.9% | — |
