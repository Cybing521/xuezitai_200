# 睡眠数据统计分析 — 交付清单

## 项目概述
- 研究对象：62例睡眠障碍患者（1组31例 vs 2组31例）
- 观察指标：总睡眠时间、睡眠效率、WASO、睡眠潜伏期
- 统计方法：Wilcoxon符号秩检验、Mann-Whitney U检验、Fisher精确检验
- 描述统计：M(P25, P75)，非参数方法

## 主要结论
1. 两组基线无显著差异（P>0.05）
2. 两组治疗后各指标均显著改善（P<0.01）
3. 2组改善幅度显著优于1组（P≤0.010）
4. 总有效率：1组45.2% vs 2组80.6%（Fisher P=0.008）
5. 治疗后睡眠时间全部≤493min
